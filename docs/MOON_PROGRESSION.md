# Moon Progression

Galacticraft's existing order is preserved: refinery fuel, NASA Workbench, Tier 1 rocket, 3×3 launch pad, oxygen gear/mask/tanks, and launch to the Moon. Establish power and oxygen, defeat/complete normal Moon dungeon progression, and obtain the Tier 2 rocket schematic path.

The Analyzer recipe requires raw meteoric iron (`galacticraftcore:meteoric_iron_raw`) as its Moon-derived scientific component. This makes Moon material part of the final cross-system machine without creating a new lunar processing tree.

IndustrialCivilizationCore records the first dimension transition whose provider name contains `Moon`. Galacticraft remains the enforcement mechanism; the core logs/flags sequence validation for the later Mars transition.
