# Quest Background Generation Prompts

Reference image for every prompt: `docs/art/industrial_content_concept.png`.

The shipped outputs are resized to 512×512 and live in `resources/industrialcivilizationcore/textures/gui/`. Original generated files remain in the Codex generated-image directory recorded in the implementation handoff.

## Earth industry

Create a square 1:1 pixel-art background for a Minecraft 1.12 Better Questing quest-map canvas, EARTH INDUSTRIAL ERA. Match the attached/reference Industrial Civilization concept direction: classic IC2-style restrained pixel art, steel-gray machine casings, copper accents, cyan indicator lights. Show a compact workshop evolving into a sprawling electrified factory, with distant smokestacks, cables, rail freight, and a subtle reactor silhouette. Dark low-contrast composition with open uncluttered central and horizontal areas so quest nodes and connector lines remain readable. No words, no letters, no logos, no UI frame, no item icons, no magenta, no photorealism. Crisp pixel clusters, limited palette, atmospheric depth.
