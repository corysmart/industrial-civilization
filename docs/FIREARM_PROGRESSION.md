# Firearm Progression

The required campaign route avoids multi-layer part microcrafting:

1. Railcraft/ore-dictionary steel and IC2 circuits unlock a Techguns pistol and magazines.
2. A combat shotgun adds iron, steel, rubber, and a wooden stock route.
3. The M4 advanced rifle requires steel, copper, aluminum, rubber, glass, and an IC2 advanced circuit.
4. Pistol magazines, shotgun shells, and assault-rifle magazines use copper/steel, propellant, and electronics where appropriate.

Recipes are in `groovy/postInit/industrial_civilization.groovy` and can be refreshed with `/gs reload --clean`. Techguns' powered machines and remaining catalogue remain available, so optics, attachments, grenades, launchers, marksman/sniper weapons, machine guns, and mounted/turret systems can still be explored without installing a second gun framework.

The required manufactured set is: `techguns:pistol`, `techguns:combatshotgun`, `techguns:m4`, `techguns:pistolmagazine`, `techguns:shotgunrounds`, and `techguns:assaultriflemagazine`.
